# Contributing to TrustNode

Thank you for your interest in contributing to TrustNode! As a self-hosted AI-powered VAPT platform, we welcome community participation to improve features, scan rules, documentation, and the overall developer experience.

By contributing to this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

### Reporting Bugs
* Search the existing issues before opening a new one.
* Use the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md).
* Provide clear, reproducible steps, your environment info, and relevant logs (ensuring you sanitize private keys, license codes, or target details).

### Requesting Features
* We encourage suggestions for new security scanners, integrations, or AI logic improvements.
* Please submit feature requests using the [Feature Request template](.github/ISSUE_TEMPLATE/feature_request.md).

### Code Contributions
1. Fork the repository and create your branch from `main`.
2. Install dependencies and set up the local development environment using Docker.
3. Make your changes, ensuring code matches the formatting rules specified in `.editorconfig`.
4. Add or update tests where applicable.
5. Submit a Pull Request targeting the `main` branch.

## Pull Request Guidelines

* Follow the [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md).
* Keep your changes focused. Do not mix unrelated refactors and feature implementation in a single PR.
* Write clear, descriptive commit messages.
* Ensure all CI checks (linting, testing) pass successfully.
